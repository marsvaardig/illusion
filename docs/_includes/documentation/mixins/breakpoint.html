--- ### @mixin breakpoint Media query shortcut. Sets a temporary global `$inside-breakpoint` variable to be used inside other mixins. #### Arguments | Name | Type | Default | Description | | ---- | ---- | ------- | ----------- | | `width` | `string` | - | min-width amount | | `width--max` | `string` | `false` | max-width amount for `(min-width) and (max-width)` media query | | `type` | `string` | `inherit` | `inherit` uses the widths as they are. `em` or `rem` converts px widths, 16px per `em` as in all media queries. `px` converts `em` and `rem` widths | #### SCSS {% highlight css %} .foo { @include breakpoint($bravo) { width: auto; } } {% endhighlight %} #### CSS {% highlight css %} @media screen and (min-width: 560px) { .foo { width: auto; } } {% endhighlight %}
