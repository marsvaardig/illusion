--- ### @mixin transition Shortcut to set one or more transition properties. #### Arguments | Name | Type | Default | Description | | ---- | ---- | ------- | ----------- | | `transitions` | `list` | `all` | Comma separated list. Each item can have up to four values (property, duration, easing, delay). Missing values fall back to `$illusion-transition-duration` (`200ms`), `$illusion-transition-easing` and `$illusion-transition-delay` (`0ms`) | #### SCSS {% highlight css %} .foo { @include transition(opacity 1s, transform); } {% endhighlight %} #### CSS {% highlight css %} .foo { transition: opacity 1s cubic-bezier(0.195, 0.4, 0.45, 0.785) 0ms, transform 200ms cubic-bezier(0.195, 0.4, 0.45, 0.785) 0ms; } {% endhighlight %}
