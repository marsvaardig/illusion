--- ### @mixin fluid-property Fluid value between two breakpoints. With `$illusion-fluid-property-clamp: true` the in-between media query is replaced by a `clamp()` inside `@supports`. With `$illusion-logical-properties: true` only a `clamp()` is output. Use the same unit for the values and the screens; other units give a warning. See also the `fluid()` function. #### Arguments | Name | Type | Default | Description | | ---- | ---- | ------- | ----------- | | `property` | `string` | - | The property to set | | `min-value` | `string` | `$illusion-fluid-property-min-value` | The minimum value. Defaults to `$font-size` | | `max-value` | `string` | `$illusion-fluid-property-max-value` | The maximum value. Defaults to `20px` | | `min-screen` | `string` | `$illusion-fluid-property-min-screen` | Breakpoint for fluid-property to kick in. Defaults to `$bravo` | | `max-screen` | `string` | `$illusion-fluid-property-max-screen` | Breakpoint for fluid-property to stop. Defaults to `$delta` | #### SCSS {% highlight css %} .foo { @include fluid-property(font-size, 16px, 24px); } {% endhighlight %} #### CSS {% highlight css %} .foo { font-size: 16px; } @media screen and (min-width: 560px) { .foo { font-size: calc(1.724137931vw + 6.3448275862px); } } @media screen and (min-width: 1024px) { .foo { font-size: 24px; } } {% endhighlight %}
