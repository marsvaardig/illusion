--- ### @mixin ratio-block Create blocks that keep set aspect ratio. Blocks will grow when content exceeds the content area. To stop this add an absolute positioned child to the ratio block. #### Arguments | Name | Type | Default | Description | | ---- | ---- | ------- | ----------- | | `ratio` | `list` | `16 by 9` | Width to height ratio | | `overflow` | `string` | `hidden` | Hides overflowing content when an absolute positioned child exceeds the content area | | `after` | `boolean` | `true` | Adds an `::after` element that clears the floated `::before` element | #### SCSS {% highlight css %} .foo { @include ratio-block(4 by 3); } {% endhighlight %} #### CSS {% highlight css %} .foo { overflow: hidden; } .foo::before { display: block; float: left; content: " "; padding-top: 75%; } .foo::after { content: " "; clear: left; display: table; } {% endhighlight %}
