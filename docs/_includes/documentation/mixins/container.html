--- ### @mixin container Shouldn't be nested. Adds clearfix when used without flexbox and removes clearfix when used as flexbox. Adds a max-width and left and right padding following the responsive gutters. #### Arguments | Name | Type | Default | Description | | ---- | ---- | ------- | ----------- | | `type` | `string` | `$illusion-grid-container-type` | `flex` for a flexbox container, any other value for a clearfix (float) container. Defaults to `float` | | `align` | `string` | `center` | Align container to left, center or right | #### SCSS {% highlight css %} .foo { @include container; } {% endhighlight %} #### CSS {% highlight css %} .foo { max-width: 1176px; margin-left: auto; margin-right: auto; } .foo::before, .foo::after { display: table; content: " "; } .foo::after { clear: both; } .foo { padding-left: 16px; padding-right: 16px; } @media screen and (min-width: 560px) { .foo { padding-left: 24px; padding-right: 24px; } } @media screen and (min-width: 1024px) { .foo { padding-left: 32px; padding-right: 32px; } } {% endhighlight %}
