--- ### @function spacing() Returns the gutter of the current breakpoint times `multiplier`, also within a breakpoint. Outside a breakpoint it uses the smallest gutter. #### Arguments | Name | Type | Default | Description | | ---- | ---- | ------- | ----------- | | `multiplier` | `number` | `1` | Gutter multiplier. defaults to `1` and can be set to any number dividable by `0.5` | | `breakpoint` | `string` | `false` | Name of a breakpoint in `$illusion-grid-breakpoints` (`default`, `bravo` or `delta`) to return the gutter of | #### SCSS {% highlight css %} .foo { @include breakpoint($bravo) { padding-top: spacing(); } } {% endhighlight %} #### CSS {% highlight css %} @media screen and (min-width: 560px) { .foo { padding-top: 24px; } } {% endhighlight %}
