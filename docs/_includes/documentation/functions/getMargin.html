--- ### @function get-margin() Returns the gutter (margin) times `multiplier`, also within a breakpoint. Outside a breakpoint it uses the smallest gutter. #### Arguments | Name | Type | Default | Description | | ---- | ---- | ------- | ----------- | | `multiplier` | `number` | `1` | Multiplier. defaults to `1` and can be set to any number dividable by `0.5` | #### SCSS {% highlight css %} .foo { @include breakpoint($bravo) { margin-top: get-margin(); } } {% endhighlight %} #### CSS {% highlight css %} @media screen and (min-width: 560px) { .foo { margin-top: 24px; } } {% endhighlight %}
