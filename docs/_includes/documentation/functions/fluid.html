--- ### @function fluid() Scales a value fluidly between two viewport widths and returns a `clamp()` in `rem`. Give it the value from the mobile design and the value from the desktop design, in design pixels. A `$min` larger than `$max` gives a value that shrinks as the viewport grows. #### Arguments | Name | Type | Default | Description | | ---- | ---- | ------- | ----------- | | `min` | `number` | - | Value at the `from` viewport width. Unitless, `px`, `rem` or `em` | | `max` | `number` | - | Value at the `to` viewport width. Unitless, `px`, `rem` or `em` | | `from` | `number` | `$illusion-fluid-from` | Viewport width where scaling starts. Defaults to `$alfa` | | `to` | `number` | `$illusion-fluid-to` | Viewport width where scaling stops. Defaults to `$illusion-grid-maxwidth` | #### SCSS {% highlight css %} .foo { font-size: fluid(16, 24); margin-top: fluid(40, 16); } {% endhighlight %} #### CSS {% highlight css %} .foo { font-size: clamp(0.8889rem, 0.7093rem + 1.0101vw, 1.3333rem); margin-top: clamp(0.8889rem, 2.7609rem - 3.0303vw, 2.2222rem); } {% endhighlight %}
